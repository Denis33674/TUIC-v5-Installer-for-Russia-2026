# TUIC v5 Installer для России 2026

Простой и удобный скрипт для быстрой установки **TUIC v5** — одного из самых устойчивых протоколов против DPI в России на 2026 год.

---

## Возможности

- Автоматическая установка последней версии TUIC v5
- Генерация сильных UUID и пароля
- Готовая конфигурация, оптимизированная под Россию
- Автоматический systemd сервис
- Вывод готовой клиентской ссылки
- Поддержка Hiddify, Shadowrocket, Sing-box и других клиентов
